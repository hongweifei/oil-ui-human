Oil UI 是面向 AI 代理的界面设计 Skill：首先提出若干真正存在差异的设计方向供用户选择，随后依据实际画面进行打磨。网站、应用、后台与组件界面均可胜任。更多设计效果请参见 [ui.oiloil.org](https://ui.oiloil.org/?utm_source=github&utm_medium=referral&utm_campaign=readme-zh)。

## 设计方法

1. **首先判明产品所属品类。** 动手之前，先明确该产品的类别，进而找出同类中风格最鲜明的两三家，考察其做法与背后理由，然后决定哪些予以沿用、哪些需要更换。
2. **将"高级""简洁"转化为具体决策。** 这类词汇人人皆会使用，却无法落到画面之上。该方法先从题材、受众和品牌语气确定调性，例如喧闹还是安静、精致还是粗粝、信息排布紧密还是疏朗，再将调性转化为可见的设计选择：使用何种字体、保留多少留白、颜色占据多大面积。
3. **每个方向均由一个具体出发点推导。** 可以是一种材质及其所处环境、一个场景、一个角色，也可以借用另一领域的整套表现方式。灵感源自产品本身，而非"简约""大气"之类的形容词。
4. **首先确定首屏服务于何种目的。** 用于浏览内容、挑选商品或处理事务的页面，首屏应当就是内容本身；唯有以说服为目的的页面，才需要在撰写文案之前先确定首屏的版式。
5. **各方向之间必须存在实质差异。** 版式、字体、配色和主视觉四项之中，任意两个方向最多只能有一项相同。小样完成后并列放置，眯起眼睛观察首屏的明暗分布；若过于相似，则重新确定版式，不依靠更换颜色补救。
6. **保留一处令人印象深刻的细节。** 不追求整页均施加强表现，仅将一两处做到极致，例如点按时的反馈、付款成功的瞬间、AI 执行任务的过程，或者一个 404 页面；其余位置保持克制。
7. **观感优劣由用户裁定。** 数份小样置于同一对比页中，由用户选定一个，并说明具体喜欢与不喜欢的方面。设计方依据反馈收紧方案之后，再继续推进。
8. **以真实画面为验收依据。** 完成后在桌面端与移动端尺寸下打开页面并截图检查，也可以邀请一位未曾接触制作过程的评审指出问题。最后执行一轮减法：每页只保留一个主角，删除不影响理解的文字、重复的线条与多余的边框。

若需要提升界面易用性、改造既有项目，或制作流光、点阵这类特效，请参见 [Oil UI Pro](https://ui.oiloil.org/pro/?utm_source=github&utm_medium=referral&utm_campaign=readme-zh)，差异详见[下文](#开源版与-pro)。

## 安装

将下列指令交给支持安装 Skill 的代理：

```text
请为我安装这个 Skill：运行 npx skills add oil-oil/oil-ui
```

或者在终端中执行：

```bash
npx skills add oil-oil/oil-ui
```

安装后即可使用，无需额外配置。存在新版本时，代理会在回复末尾予以提示，如需更新可随时要求其执行。已安装 Oil UI Pro 的情况下无需再安装开源版，两者同时安装会争抢同一类请求。

若使用 DeepSeek Harness，可安装原生插件 [dsh-oil-ui](https://github.com/oil-oil/dsh-oil-ui)（`dsh plugin --profile web add github:oil-oil/dsh-oil-ui`；其中内置免费版，并会自动识别本机已安装的 Oil UI Pro）。

## 使用方式

直接将任务告知代理，例如：

- "使用 oil-ui 为这个课程预约产品探索几种设计方向，制作成可以预览的页面。"
- "制作三种字体、配色和构图均不相同的设计，置于对比页中供我选择。"
- "依照项目现有的设计规范润色这个页面。"
- "仅对这个首页进行评审，说明需要修改之处与方法，不要改动文件。"
- "按照这张截图还原页面，参考图中未包含的手机布局也一并补充。"

如有品牌资料、截图或既有项目，可一并提供。即使没有参考材料也能开始工作，只有在交付目标不明确时才会向用户提问。

## 版本检查

每次使用时，Skill 会检查是否存在新版本，最多每 10 分钟联网一次。它只读取 ui.oiloil.org 公开提供的版本列表，不上传项目内容；默认仅予以提示，不下载、不替换任何文件，只有在用户明确要求更新时才执行更新操作。检查结果缓存在 `~/.local/state/oil/`（设置 `XDG_STATE_HOME` 时使用该路径；Windows 下为 `%LOCALAPPDATA%\oil\`）。运行需要 Python 3；如不希望执行检查，请设置环境变量 `OIL_NO_UPDATE_CHECK=1`。
