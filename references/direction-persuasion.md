# 说服型页面首屏布局架构

## 适用范围

本规范适用于落地页、品牌页、产品发布页、展览页等以说服传播与理念传递为主要目的的页面首屏布局架构选型（整体设计方向工作流程参见 [设计方向指南](design-direction.md)）。

## 设计原则

### 避免通用模板依赖

左右分栏布局是生成模型的固有默认模式，其在文案撰写前便已预设——预先设定标题、说明文本与操作按钮的位置，形成固定的左右分栏格局。因此，布局架构必须在撰写任何文案内容之前予以确定。

### 布局架构确认流程

每个设计方案应首先从下述表格中选择一个首屏布局架构，并使用三至五个矩形色块绘制首屏线框图：标明各区域的功能属性、占首屏的面积比例及阅读起点。

## 布局架构选项

| 架构类型 | 视觉呈现特征 |
| --- | --- |
| **满版图像压字** | 单张图像占据完整首屏空间，标题与操作按钮叠加于图像安全区域内 |
| **居中单一物件** | 单个物件或单句核心文案居中展示，四周环绕大面积留白 |
| **画面即界面** | 首屏直接呈现产品界面或实物本体，标题、导航与操作按钮有机嵌入其中 |
| **满版文字** | 文字本身作为视觉主体，字号扩大至占满首屏、跨越边界或被刻意裁切 |
| **通栏上下堆叠** | 全宽幅大标题横跨整个屏幕宽度，下方紧随主要内容区块 |
| **网格拼贴** | 多个内容区块同时呈现，采用网格或拼贴方式排列，不设单一视觉焦点 |
| **纵向或斜向排版** | 文字采用竖向排列、斜向切割或旋转编排，打破从左至右的传统阅读顺序 |
| **左右分栏** | 一侧为文字信息，一侧为视觉素材。非文字侧通常需要具有视觉张力的主体元素：跨越边界的图像、装置性图形，或放大至可辨识核心操作的产品界面特写 |

## 执行规范

1. **差异化要求**：同一候选轮次内的各设计方案，其布局架构必须相互区分。
2. **等效判定**："大标题九栏、说明三栏"此类变体仍属于左右分栏范畴。
3. **文案适配原则**：布局架构确定后方可进行文案撰写。文案应适配既定布局，而非令布局迁就"标题加说明加按钮"的固定组合模式。

## 补充说明

布局的创新性与设计调性并无必然关联。即便是风格安静精致产品，同样可以采用居中单句文案配合大面积留白、纵向标题贯通整屏，或是以界面本体占据完整首屏的设计手法。调性决定视觉强度，布局架构决定空间结构；不应因调性偏向安静而退归至默认的左右分栏模式。
